# 🏥 MedGuide - Healthcare Management System

A complete full-stack healthcare management platform built with React, TypeScript, Node.js, Express, and MySQL.

## ✨ Features

### 👨‍⚕️ For Doctors
- Complete profile management with verification system
- Appointment management (accept/reject/complete)
- Digital prescription creation with PDF generation
- Patient management dashboard
- Analytics and statistics
- Review and rating system
- Schedule management

### 👤 For Patients
- Search and book appointments with verified doctors
- Complete health profile management
- Digital prescription access and download
- Medical reports upload and management
- Medical timeline tracking
- Doctor reviews and ratings
- Appointment history and management

### 🔐 For Admin
- Doctor verification system
- User management
- Medicine database management
- Comprehensive analytics dashboard
- Appointment monitoring
- System-wide statistics

### 🌟 Additional Features
- Secure JWT authentication
- Role-based access control
- Email notifications
- Symptom checker
- Medicine information database
- Responsive design
- Modern UI with animations
- PDF generation for prescriptions
- Real-time data updates

## 🛠️ Tech Stack

### Frontend
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- React Router v6
- Axios
- Recharts
- React Hot Toast

### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication
- Bcrypt
- Nodemailer
- Multer
- PDFKit

## 📋 Prerequisites

Before you begin, ensure you have the following installed:
- Node.js (v16 or higher)
- npm or yarn
- MySQL (v8.0 or higher)
- XAMPP (for Windows users) or LAMP/MAMP stack
